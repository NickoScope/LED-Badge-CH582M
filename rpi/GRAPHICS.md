## Кадр

Панель 44 столбца на 11 строк, монохром. Кадр — список из 44 целых, по одному
на столбец. **Бит 0 — верхний пиксель**, значимы биты 0..10.

```python
frame = [0] * 44
frame[0]  = 0b00000000001   # верхний пиксель первого столбца
frame[1]  = 0b10000000000   # нижний пиксель второго
frame[2]  = 0x07FF          # весь столбец
```

Такой же порядок ждёт `stream_bitmap`, поэтому перекладывать ничего не надо.
Кадр целиком — `1 + 44*2 = 89` байт.

## Canvas — рисование

```python
from badge.canvas import Canvas
c = Canvas()
```

Все методы возвращают `self`, поэтому пишутся цепочкой.

| Метод | Что делает |
|---|---|
| `clear()` | погасить всё |
| `px(x, y, on=True)` | точка; `on=False` гасит |
| `vbar(x, height, from_bottom=True)` | вертикальный столбик — полосы спектра, шкалы |
| `hline(y, x0=0, x1=None)` | горизонтальная линия — земля, рамка |
| `blit(cols, x=0, mode="or")` | наложить готовые столбцы; `mode="set"` перезаписывает |
| `text(s, x=0, center=False, tiny=False)` | надпись |
| `progress(frac, y=None)` | полоса заполнения по строке; по умолчанию нижняя |
| `shift_up(n=1)` | сдвинуть всё вверх на n пикселей |
| `frame()` | отдать кадр списком |

```python
c = (Canvas()
     .hline(10)                    # земля
     .vbar(20, 4)                  # препятствие
     .text("GO", center=True)
     .progress(0.35))
frame = c.frame()
```

## Текст и шрифты

```python
from badge.canvas import text_columns, tiny_columns
```

`text_columns(text, height=11, font_path=None, tight=True)` рисует через Pillow.
Шрифт ищется среди системных (DejaVu, Liberation, Menlo), можно задать свой путь.
`tight=True` обрезает пустые столбцы по краям.

`tiny_columns(text)` — встроенный шрифт 3x5 без внешних файлов. Только цифры,
двоеточие, дефис, точка и пробел, зато работает всегда. Часы им рисуются даже
на системе без единого ttf.

**Важно.** Не используйте `SimpleTextAndIcons.bitmap()` из led-name-badge-ls32:
двоеточие там — синтаксис вставки иконок, и `"23:18:35"` превращается в `chr(18)`
с падением, причём в зависимости от минуты. Наш `text_columns()` рисует
посимвольно и этой ловушки не имеет. Апстрим: led-name-badge-ls32 issue #22.

Оценка ширины: `HH:MM` плотной отрисовкой — около 30 столбцов, `HH:MM:SS` — 52,
то есть в панель уже не влезает. Поэтому в источнике `clock` секунды показаны
полосой по нижней строке, а не цифрами.

## Scroller — бегущая строка

```python
from badge.canvas import Scroller
sc = Scroller("ПРИВЕТ МИР", gap=8)
frame = sc.step(1.5)        # столбцов за вызов, дробное можно
sc.set_text("НОВЫЙ ТЕКСТ")  # менять на ходу
```

Строка зациклена, `gap` — пустой промежуток перед повтором.

## Источник — контракт анимации

```python
from badge.sources import Source, source

@source("mysrc")
class MySrc(Source):
    def frame(self, t):      # t — секунды с начала показа
        ...
        return cols          # список из 44 чисел
```

Декоратор регистрирует источник, и он **сразу появляется везде**: в командной
строке `badgectl stream mysrc`, в HTTP API `POST /source`, и в MCP-инструменте
`badge_set_source`. Ничего дописывать не нужно.

Параметры приходят в `self.opts`:

```bash
badgectl stream mysrc -o speed=2 -o color=1
```

Если нужен полный контроль над циклом — переопределите `run()`:

```python
class MySrc(Source):
    async def run(self, out, stop):
        while not stop.is_set():
            await out(self.build_frame())   # out сам держит темп
```

Так сделан `stdin`, который ждёт строки из потока.

## Пример: анимация

Бегущая волна с затухающим следом:

```python
import math
from badge.canvas import Canvas
from badge.sources import Source, source

@source("wave")
class Wave(Source):
    def frame(self, t):
        c = Canvas()
        speed = float(self.opts.get("speed", 4.0))
        for x in range(44):
            y = 5 + 4.5 * math.sin(x * 0.28 + t * speed)
            c.px(x, int(round(y)))
        return c.frame()
```

```bash
badgectl stream wave -o speed=6
```

## Пример: игра

Готовый образец — `Platformer` в `sources.py`: физика прыжка, генерация мира
из позиции (не из памяти), спрайты с фазами бега, параллакс облаков.

Скелет игры с состоянием:

```python
@source("dodge")
class Dodge(Source):
    def __init__(self, **opts):
        super().__init__(**opts)
        self.y = 5          # позиция игрока
        self.wx = 0.0       # позиция мира
        self.last = 0.0
        self.score = 0

    def obstacle(self, wx):          # мир вычисляется, а не хранится
        return wx > 20 and wx % 17 == 0

    def frame(self, t):
        dt = min(0.08, t - self.last); self.last = t
        self.wx += 12.0 * dt

        c = Canvas()
        wx0 = int(self.wx)
        for sx in range(44):
            if self.obstacle(wx0 + sx):
                c.vbar(sx, 4)
        c.px(6, self.y).px(6, self.y - 1)
        return c.frame()
```

**Мир лучше вычислять функцией от позиции, а не хранить списком** — уровень
получается бесконечным и не занимает памяти.

Ввода с кнопок пока нет: прошивка не сообщает о нажатиях. Разбор и план правки —
в [../IDEAS.md](../IDEAS.md). До этого управление возможно с клавиатуры хоста.


## Разбор: платформер целиком

`Platformer` в `sources.py` — рабочая игра на сотню строк. Ниже разобрано,
почему она устроена именно так; приёмы переносятся на любую другую.

### 1. Мир не хранится, а вычисляется

Соблазн — держать список препятствий и дописывать его по мере бега. На бейдже
это плохая идея: памяти 32 КБ, а уровень бесконечен. Поэтому мир — **чистые
функции от координаты**:

```python
def _pipe_h(self, wx):
    if wx < 24 or wx % 19 not in (0, 1, 2):
        return 0
    return 2 + (wx // 19) % 3
```

Труба шириной три столбца каждые 19, высота 2..4 циклично. Ям и монет то же
самое. Следствия приятные: уровень бесконечен, памяти не ест, **воспроизводим**
(на 500-м столбце всегда одно и то же), и можно спрашивать «что будет через
семь шагов» — это и делает авто-игрок.

`wx < 24` в начале — чтобы первые секунды были пустыми и игрок успел понять,
что происходит.

### 2. Камера стоит, мир едет

Герой всегда в столбце `HERO_X = 7`, движется `wx`. Отрисовка переводит
экранный столбец в мировой:

```python
wx0 = int(self.wx)
for sx in range(COLS):
    wx = wx0 + sx
```

`wx` дробное, `wx0` целое — прокрутка плавная по времени, но рисуем по целым.

### 3. Физика: считать, а не подбирать

Здесь я допустил ошибку, которую стоит показать. Сначала были `g = 22` и
скорость `6.8`, взятые на глаз. Прыжок вышел **высотой в один пиксель**, и
монеты на высоте 5 не собирались вообще — счётчик стоял на нуле.

Высота прыжка считается формулой:

```
h = v² / (2g)
```

Нужно 4-5 пикселей. При `g = 26` получаем `v = sqrt(2 * 26 * 5) ≈ 16`. Отсюда
нынешние числа:

```python
self.vy = 16.0 if need >= 3 or self._gap(hx + d) else 14.0   # 4.9 и 3.8 px
self.vy -= 26.0 * dt
```

Мораль: на панели в одиннадцать пикселей «примерно похожие» константы не
работают — масштаб слишком мал, ошибка вдвое видна сразу.

### 4. dt ограничен сверху

```python
dt = min(0.08, max(0.0, t - self.last))
```

Если поток притормозил — переподключение, задержка BLE — большой `dt` телепортирует
героя сквозь препятствие. Ограничение сверху превращает провал в замедление,
что глазу гораздо приятнее. Стандартный приём игровых циклов.

### 5. Авто-игрок: смотреть вперёд

```python
def _obstacle_ahead(self, wx, look=7):
    for d in range(2, look):
        if self._pipe_h(wx + d) or self._gap(wx + d):
            return d
    return 0
```

Семь столбцов — примерно полсекунды на скорости 11 столбцов в секунду, как раз
время подъёма. Прыгает сильнее, если труба высокая или впереди яма. Если чисто —
проверяет монеты и подпрыгивает за ними:

```python
for k in range(2, 6):
    if self._coin(hx + k) and (hx + k) not in self.taken:
        self.vy = 15.0
        break
```

Именно это место станет обработчиком кнопки, когда появится ввод: вместо
«решил сам» будет «нажали `KEY1`».

### 6. Порядок отрисовки

Сначала дальнее, потом ближнее — как в живописи:

**Облака** идут первыми и **вдвое медленнее**:

```python
cwx = int(self.wx * 0.5) + sx
```

Это параллакс. Приём из восьмидесятых, и на одиннадцати пикселях он тоже
читается: мозг видит глубину, хотя картинка плоская.

**Земля, трубы, ямы, монеты, флаг** — один проход по столбцам.

**Герой** — последним, поверх всего.

### 7. Спрайты строками

```python
RUN = (("010", "111", "010", "101", "101"),
       ("010", "111", "010", "110", "011"))
JUMP =  ("111", "010", "111", "101", "100")
```

Три на пять пикселей. Две фазы бега отличаются ногами, переключаются от времени:
`int(t * 9) % 2` — девять раз в секунду. У прыжка руки вверх и ноги вместе.

Строками, а не числами, чтобы **рисунок был виден прямо в коде**. Правится
за секунду, без пересчёта битов.

### 8. Подбор монеты — пересечение, а не порог

Первая версия проверяла «высота прыжка больше трёх» и не работала, потому что
прыжок был низкий. Правильно — проверять пересечение спрайта со строкой монеты:

```python
if self._coin(w) and w not in self.taken and top <= self.GROUND - 5 <= top + 4:
```

`top` — верхняя строка спрайта, `top + 4` — нижняя. Условие не зависит от того,
какой высоты прыжок и где висит монета: геометрия проверяется как геометрия.

Собранные монеты помнятся в `self.taken` — множестве мировых координат. Это
единственное состояние, которое действительно нужно хранить: всё остальное
вычисляется.

### 9. Что померили

30 кадров в секунду, 3602 кадра за две минуты, ни одного пропуска. На скорости
11 столбцов в секунду выходит около 93 прыжков и 100 монет, на 7.5 — заметно
спокойнее и монет меньше, потому что герой пробегает меньше пути.

### 10. Как сделать играбельной

Заменить блок «авто-игрок» на чтение очереди нажатий, и оставить старое
поведение под ключом:

```python
if self.opts.get("auto", False):
    ...прежняя логика...
elif key_pressed:
    self.vy = 16.0
```

Ввода пока нет — прошивка не сообщает о нажатиях. Разбор и план правки:
[../IDEAS.md](../IDEAS.md).

## Сохранить во флеш

Анимация, записанная в бейдж, играет без компьютера:

```python
from badge.proto import legacy_payload
frames = [cols for cols in my_frames]        # каждый по 44 столбца
payload = legacy_payload([sum(frames, [])], speeds=6, modes=5)  # режим 5 — animation
```

Проще через готовый инструмент: `make_film.py` в корне репозитория собирает
48 кадров и заливает.

**Предел — около 60 кадров.** 120 кадров роняют прошивку при старте, и
восстановление требует аппаратного входа в ISP. `Badge.upload()` откажется
грузить заведомо опасное. Апстрим: issue #195.

## Что помнить про железо

**Градаций серого нет.** Яркость общая на всю панель, четыре уровня
(`badge_set_brightness` 0..3), не по пикселям.

**30 кадров в секунду** — заданный клиентом потолок, не предел железа.
Ставится через `BADGE_FPS` или `Badge(target_fps=...)`.

**Темп задаёт клиент.** При записи без подтверждения обратной связи нет,
и цикл без ограничения забивает очередь стека. В `Badge.stream()` это уже сделано.

**Ширина кадра зависит от прошивки.** С патчем MTU — все 44 столбца одной
посылкой. Без него — 30, и правая часть панели останется статичной.
Проверить: `badgectl info`, поле `full_width`.

**Поток не хранится.** Отключите хост — картинка замрёт на последнем кадре.
Для автономной работы нужна запись во флеш.
